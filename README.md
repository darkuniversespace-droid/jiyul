# 🔁 StudyLoop (스터디루프)

> AI 학습 & 컨디션 케어 플래너

## 소개

교과서·학교 프린트를 AI가 읽고 심화 개념과 퀴즈를 만들어 주며, 어젯밤 수면과 스마트폰 사용 패턴에 맞춰 오늘의 공부 강도와 시간표를 자동으로 조절하는 학습 플래너입니다. 에빙하우스 망각 곡선으로 복습을 예약하고, 어제 공부한 내용으로 다음 날 맞춤 퀴즈를 출제합니다.

## 사용자 스토리 (기능 목록)

1. **📚 교과서 및 학습 프린트 멀티 연동**
   - 과목별 출판사 설정 및 교과서 PDF 업로드 & 데이터 저장
   - 학교 프린트/학습지 사진 촬영 업로드
   - 교과서·프린트 내용 기반의 심화 개념, 확장 지식, 맞춤형 퀴즈 자동 생성
2. **🌐 매일 영어 독해 (Breaking News English 연동)**
   - Breaking News English에서 매일 짧은 영어 지문과 관련 학습 자료 자동 로딩
3. **🛌 바이오리듬 & 디지털 습관 연동**
   - 수면 데이터: 어젯밤 수면 분석 후 당일 공부 강도·스케줄 자동 조절
   - 스마트폰 사용 시간: 스마트폰 사용 패턴 분석 및 피드백
4. **🗓️ 스마트 스케줄링 & 복습 시스템**
   - 교재 분량 자동 분배
   - 기상/취침 시간 및 당일 일정에 맞춘 유동적 시간대별 스케줄링
   - 에빙하우스 망각 곡선 기반 복습 주기 캘린더 연동 & 밀린 공부 자동 재조정
5. **🎯 집중 & 맞춤형 복습 퀴즈**
   - 집중 타이머 & 백색소음
   - 어제 공부 기록을 바탕으로 다음 날 AI가 출제하는 맞춤형 복습 퀴즈

## 주요 수용 기준 (Acceptance Criteria)

- **교과서/프린트 인식:** 업로드한 교과서 PDF 및 촬영한 프린트 사진의 텍스트와 개념을 AI가 정확히 파악해 저장할 것.
- **외부 데이터 연동:** Breaking News English의 최신 영어 지문과 자료가 오류 없이 매일 정상 로딩될 것.
- **생체/디지털 데이터 연동:** 수면 시간과 스마트폰 사용 시간 데이터를 불러와 당일 스케줄·강도 계산에 반영할 것.
- **스마트 스케줄링:** 기상/취침 시간 및 당일 일정을 고려해 시간대별 스케줄이 유연하게 생성되고, 에빙하우스 주기에 맞춰 복습 캘린더와 다음 날 복습 퀴즈가 자동 연동될 것.

## 제약 (Constraints)

- **설치·빌드 없음:** `index.html`만 열면 동작해야 함 (정적 파일, 번들러/서버 불필요).
- **배포:** GitHub에 올려 GitHub Pages(웹)로 공개.
- **개인정보 및 보안:** 수면·스마트폰 사용 데이터는 사용자 기기 권한과 동의 기반으로만 연동하며, 민감한 생체 정보는 외부 서버에 무단 저장하지 않음.
- **저작권 준수:** 교과서 PDF 및 Breaking News English 데이터는 개인 학습(Fair Use) 범위를 넘는 상업적 배포·재가공을 하지 않음.
- **AI 토큰/처리 용량:** 대용량 PDF·고해상도 사진은 AI 입력 한계와 지연을 고려해 압축·분할 처리.

## 데이터 출처 (Data Sources)

- **영어 뉴스/지문:** Breaking News English 공식 사이트 및 공개 RSS 피드 파싱.
- **수면 및 기기 사용 통계:** Android/iOS 공식 Digital Wellbeing API, Samsung Health SDK를 통한 시스템 표준 데이터.
- **교과서/프린트 학습 자료:** 외부 DB 없이 사용자가 업로드한 PDF·사진을 LLM의 비전/텍스트 분석으로 해석·확장.

## 사용 / 배포

- **사용:** `index.html`을 브라우저로 열면 끝. ⚙ 설정에서 [Gemini API 키](https://aistudio.google.com/apikey)를 입력하면 AI 기능이 켜집니다 (키는 기기 localStorage에만 저장).
- **웹 공개:** 저장소에 `index.html`, `README.md`를 올린 뒤 Settings → Pages → Branch `main` / root 선택.
- **웹 환경 한계:** 수면·스마트폰 사용 데이터는 직접 입력하고, 영어 지문은 공개 CORS 프록시로 불러오되 실패 시 붙여넣기/내장 샘플로 대체합니다.


## v2 추가 사항

- **흑백 UI**, **학기중/방학 모드** 전환 (학기중엔 학교 시간을 빼고 계획).
- **NEIS 연동**: 학교 선택 → 시간표·급식·학사일정 불러오기 (설정 > 학교 설정, 무료 인증키 권장).
- **캘린더에서 날짜를 눌러 일정/시험 바로 추가**. 시험 등록 시 시험 7일 전까지 모든 복습이 끝나도록 자동 재배치.
- **교재**: 전체 분량과 "며칠 안에" 입력.
- **스마트폰 사용 시간은 일정에 반영하지 않고 통계(그래프)로만 제공.**
- **📝 AI 오답노트**: 문제 사진 → 자동 인식·저장, 취약 단원/유형 분석, 에빙하우스 복습·맞춤 퀴즈에 자동 반영.
- **📊 통계**: 하루/주/월 이행률, 공부 시간, 수면, 스마트폰 그래프와 종합 분석(수면-오답 연관 포함).
## 범위 밖 (Out of Scope)

- 교과서·지문의 상업적 배포 및 공유
- 외부 오픈 학습 DB 수집
